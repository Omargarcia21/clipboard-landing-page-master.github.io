# Solución al Desafío de Frontend Mentor: Landing Page de Clipboard

![Badge](https://img.shields.io/badge/Estado-Completado-brightgreen)  
Este es mi solución al desafío **Clipboard Landing Page** de Frontend Mentor. El objetivo era crear una landing page estática y responsiva que incluye un **header**, un **footer**, secciones de información y botones de llamada a la acción (CTA).

**Desafío de Frontend Mentor:** [Clipboard Landing Page](https://www.frontendmentor.io/challenges/clipboard-landing-page-5cc9bccd6c4c91111378ecb9)  
**Live Demo:** [Ver Proyecto en Vivo](https://omargarcia21.github.io/clipboard-landing-page-master.github.io/)

## Descripción del Proyecto

Este proyecto es una landing page estática que presenta información sobre un producto o servicio ficticio llamado **Clipboard**. La página incluye:

- Un **header** con un diseño atractivo y un botón de llamada a la acción.
- Varias **secciones de información** que describen las características y beneficios del producto.
- **Botones de descarga** para diferentes plataformas (iOS y Mac).
- Un **footer** con enlaces útiles y redes sociales.

El diseño es completamente responsivo, utilizando **CSS Flexbox** y **CSS Grid** para organizar los elementos de manera eficiente y visualmente atractiva.

## Tecnologías Utilizadas

- **Lenguajes de Programación**: HTML, CSS, JavaScript.
- **Metodologías CSS**: Flexbox y Grid para la disposición de los elementos.
- **Diseño Responsivo**: Compatible con dispositivos móviles, tablets y desktop.
- **Interactividad**: Botones de llamada a la acción y enlaces funcionales.

## Instrucciones de Instalación y Uso

Este proyecto es una página web estática, por lo que no requiere instalación.
